 ENV-UPDATE.txt — ไม่ต้องทำอะไรแล้ว (ไฟล์นี้เก็บไว้อ้างอิงเฉยๆ)
================================================================

เดิมไฟล์นี้บอกให้แก้ .env ด้วยมือ
ตอนนี้ไม่ต้องแล้ว - ระบบจัดการให้อัตโนมัติ

  ดับเบิลคลิก run.bat  ->  มันจะเรียก setup-env.js ให้เอง

setup-env.js ทำอะไร:
  - ไม่มี .env        -> คัดลอกจาก .env.example
  - มี .env อยู่แล้ว  -> เพิ่มค่าใหม่ที่ขาด + แก้ค่าที่ต้องเปลี่ยน + ลบบรรทัดซ้ำ
  - สำรองไฟล์เดิมเป็น .env.backup-<เวลา> ก่อนทุกครั้ง
  - ไม่แตะ API key / LINE token / ค่าที่คุณตั้งเอง
  - รันซ้ำกี่ครั้งก็ได้ ผลเหมือนเดิม

อยากรันเองแยกก็ได้:
  npm run setup

ค่าที่มันจะแก้ให้ (ถ้ายังเป็นค่าเก่าอยู่):
  ATR_STOP_MULT  1.5 -> 1.0   ** สำคัญมาก ถ้าไม่แก้จะไม่มีสัญญาณออกมาเลย **
  UNIVERSE_SIZE   60 -> 30    (ประหยัดโควตา API - คงไว้ 60 ก็ได้)

รายละเอียดเต็มอยู่ใน README.md หัวข้อ 2.4
