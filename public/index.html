คำเตือนความเสี่ยง
เครื่องมือนี้เป็น เครื่องมือช่วยคัดกรองหุ้น (screening tool) เท่านั้น ไม่ใช่คำแนะนำการลงทุน และไม่ใช่การรับประกันผลตอบแทนใดๆ
• คะแนนและ "Expected Move" คำนวณจากค่าสถิติย้อนหลัง (ATR) ซึ่งไม่ได้บอกอนาคต ราคาอาจเคลื่อนไหวมากหรือน้อยกว่านั้น หรือไปคนละทางก็ได้
• ราคาเป้าหมายที่คำนวณจากแนวต้าน −0.1% คือการเข้าก่อนที่ราคาจะเบรกจริง ซึ่งจำนวนมากจะกลายเป็นการเด้งกลับ ต้องมีวอลุ่มยืนยันประกอบ
• ข้อมูลมาจาก API ฟรี อาจล่าช้า ไม่ครบ หรือผิดพลาดได้ ควรตรวจสอบกับโบรกเกอร์ก่อนตัดสินใจทุกครั้ง
• การซื้อขายหุ้นระยะสั้นมีความเสี่ยงสูงที่จะสูญเสียเงินต้น ผู้ใช้รับความเสี่ยงเองทั้งหมด
